# MediaStore — многостраничный сайт

Задание 4 по дисциплине «Фронтенд-разработка для веб-дизайнеров: HTML, CSS, JavaScript»: многостраничный сайт в Git с отдельной веткой и слиянием.

- **Код:** https://github.com/nestyleonova/frontend-multipage
- **Ветки:** `main` (итог), `new-design` (обновлённая палитра)

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | главная: шапка, баннер, подборка направлений |
| `gallery.html` | галерея кадров в CSS Grid |
| `routes.html` | маршруты карточками |
| `contacts.html` | контакты и форма |

## Что сделано по заданию

1. Git установлен, имя и email настроены.
2. Проект с `index.html` и `style.css` создан и инициализирован.
3. Первый коммит — «Задание 4: многостраничный сайт».
4. Ветка `new-design`: изменена палитра сайта отдельным коммитом.
5. Ветка `new-design` слита в `main` (коммит слияния), затем правки CSS.
6. Проект опубликован на GitHub, история и ветки видны в репозитории.

## Локальный просмотр

```
python -m http.server 8125
```
